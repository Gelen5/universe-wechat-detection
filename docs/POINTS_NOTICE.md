# 积分不足提示 · 2026-10-25

- 用户钱包扣费请求返回 HTTP 402 且 detail 包含“积分不足”时，打开原生 dialog；其他错误继续走原提示，不将模型服务商额度不足混为用户余额不足。
- 展示后端原始所需积分/余额文案，以及“购买积分请联系🌍Gelen5”。复制按钮复制 `Gelen5`，失败时提示手动复制。
- 与主站统一薄荷色、字体、圆角和模糊遮罩，兼容手机。原生模态焦点约束、Escape、关闭按钮、确认按钮与遮罩关闭均可用，关闭后恢复原焦点。
- 主站公共响应处理、标准公众号对话、独立一键成文 API 和生成请求均接入同一组件。嵌入一键成文通过同源父页面显示，避免 iframe 裁切；不替换 fetch、不改变原错误处理与草稿恢复。
- 弹窗不发起充值/付费/生成请求，不更改余额及后端计费逻辑。

验证：5 项专项浏览器测试覆盖手机/桌面实际提交收到模拟 402、保留草稿、复制和 Escape、重复触发合并、排除其他错误、嵌入页面使用父弹窗，以及一键成文选题真实处理器。另 16 项移动端/首页设置相关回归通过。所有余额不足响应均为隔离测试数据，没有修改生产钱包。
