# 原 Skill 迁移验收

真源：vendor/skills/tietu_refresh/SKILL.md 与 references、scripts。

当前线上版本只实现单图视觉分析、A/B/C 与 AI 直接出字，不能视为完整迁移。

交付门禁：

- 1–8 张图片，逐张删除、按序编号，总请求体限额与解码尺寸限制。
- 多图先输出建议顺序与依据，再逐页职责、密度、缺位分析；不能强行认定用户顺序错误。
- 内容三问、视觉八维及每维可换值；无字图默认保留无字。
- 拆解后确认赛道、情绪、禁区，再生成完整 A/B/C；C 默认推荐。
- 提取数值声明，公开检索并读取来源；不能核实则显式待核实，禁止伪造核实状态。
- 原 Skill compose.py 程序渲染中文，支持纯排版与无字底图合成；参考像素不能传入生成请求。
- 同组画幅、配色、字体一致，页码齐全；内容密度决定张数。
- 调用 check.py 并展示其能力边界，不将像素检查冒充语义/OCR检查。
- 每张图片失败可重试，成功结果保留，失败退费；纯排版免图片积分。
- 四件套：成图、可复制提示词、三条六字段配文方向、分组标签；归档配置。
- 后端保存用户隔离的工作流状态，生成仅接受服务端方案 ID；避免客户端篡改任意提示词或串用方案。
- 完整浏览器多图验收与真实供应商请求成功后才能声明上线可用。
