# 热点广场阅读墙

## 设计与范围

- 与公众号创作共用浅绿背景、中文无衬线字体、圆角和轻磨砂材质；不添加数据面板、走势曲线或虚构热度。
- 一个平台一张完整色底模块：12种低饱和配色覆盖整张卡片，标题、圆点跟随平台强调色，卡片底部不再独立白底。
- 按内容宽度自适应，2560px窗口6列、1920px4列、1440px3列、1280px2列、手机1列。总览每个平台展示4条，换一批按4条轮换；选择平台保留原有最多30条阅读模式。
- 平台名称可点击展开该平台；标题15px/1.7行高、平台名称17px、辅助文字12px，复制/收藏/去创作放在标题下一行。
- 玻璃效果只用于页头和平台容器，保留不支持模糊与降低透明度的降级规则。不逐条加阴影或横线。
- 保留来源链接、快照时间、过期提示、筛选、复制、收藏、刷新及携带来源进入创作的原有流程；增加加载失败后的重试入口。

## 导航缺陷

原公共shell.js重建导航时路由表遗漏hotspots，热点脚本事后补入的节点没有同步原导航状态。现在将热点路由正式登记到公共菜单；保留原节点和事件，删除hotspots.js临时补链观察器，并统一同步active及aria-current。独立资源页和手机更多菜单也包含热点入口。

新增Tab时必须同步公共shell.js路由表，避免再次被菜单重建移除。

- 本地截图output/mint-ui/hotspots-wall-wide.png、hotspots-wall-1440.png使用隔离fixture，不代表生产热点、热度或更新时间。
- 不修改数据库、数据源与模型配置；未主动调用真实模型生成。
