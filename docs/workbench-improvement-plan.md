### 发布前代理检查与回滚

1. 核对 HTTPS 反向代理确实覆盖/追加客户端地址；检查容器实际看到的代理 peer。
2. 将该 peer 的具体地址加入 `TRUSTED_PROXY_IPS`，保留必要的回环地址；不使用 `*`。
3. 用两个可控来源验证不同客户端不会共用代理 IP 配额，伪造转发头不能改变识别结果。
4. 验证 HTTPS 登录/退出及 Set-Cookie Secure；校验一段失败退避到期后可正常登录。
5. 回滚代码时保留原数据库与账本。新字段为可选 API 参数，无数据库迁移；可回滚到上一完整提交。
