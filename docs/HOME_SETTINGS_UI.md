# 首页与设置界面 · 2026-10-25

## 设计与实现

- 首屏围绕「宇宙第一工作台」构图，文案为「你的想法，不必止于想想。」。
- 「从一个想法开始 ↗」滚动到四个真实入口：公众号、小红书、贴图号、AI 超市；不会自动生成内容或扣费。
- 文字、研究、图像和智能体模块链接到现有页面。视频与声音、自动化、智能体接入是方向展示，明确标记探索中或构想中，没有伪造可用状态。
- 原主题输入、目标选择、最近创作保留在「快速开始与最近创作」折叠区，原草稿传递与历史链接不变。
- 所有视觉由 HTML/CSS 实现，未引入依赖、远程字体或宣传大图。小屏改用流式网格；动画支持 reduced-motion。
- `static/universe-home.css` 只作用于首页。共享侧栏的尺寸和行为不改动。

## 设置入口

`static/settings-mint.css` 最后加载，覆盖旧主题对三个现有弹窗的限制：

- API 设置：1000px 上限、双模型分区，URL 与模型独占整行。
- 用户统计：1320px 上限、列表与详情双列，表格内部滚动，表头固定；小屏单列。
- 我的积分：800px 上限，余额与各类积分、明细、管理员充值保持原数据与操作。

权限校验、充值、模型连接测试、保存接口及密钥处理均沿用原实现。普通用户不显示管理员入口。下载报告、退出登录仍使用既有动作，没有新建页面。
