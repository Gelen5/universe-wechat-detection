# AI 书架与 AI 超市界面优化

## 范围

公共侧栏保持现状；新增 resources-editorial.css 仅作用于书架主内容与超市主内容，不修改公众号创作等模块内部样式。不引入依赖，不修改书籍或工具源数据。

## 书架

- 暖白背景，标题38px，副标题16px；分类14px，桌面书名16px、作者13px。
- 按真实内容宽度排2/3/4/5列，桌面1280和1440为4列，大屏为5列，避免只按窗口宽度挤压封面。
- 保留2:3封面、低饱和书色、轻微书脊和柔和投影；移除几何装饰，主要依靠排版。
- 详情说明16px/1.95行高，来源与许可13px；搜索、筛选、收藏、官方阅读入口与版权信息保留。
- 小屏隐藏重复的封面系列装饰，为长书名和作者留空间；书籍元信息中的完整书名与作者始终保留。

## 超市

- 搜索54px高、文字16px；分类横向排列，手机可滚动；移除装饰编号和统计面板感。
- 内容区按宽度排1/2/3列；工具名称17px、用途14px、来源及Star12px。
- 普通白底轻边框、无投影；精选使用克制的灰绿底，按实际精选数量填满可用宽度。
- 明确标注前往GitHub，保持原源码链接，不伪造站内运行或安装能力；保留原数据更新日期和来源说明。
- 主壳Tab与独立market页面复用同一展示规则，原搜索/分类/排序/分页/管理行为保留。

## 验证

相关书架、超市、侧栏与共享导航：52项通过、10 subtests通过；1项既有Starlette/httpx弃用提示。
