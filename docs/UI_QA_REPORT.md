## 2. 检查过的用户流程

- 首页 → 登录 / 注册 → 工具入口。
- 账号诊断：输入 → 异步任务 → 成功报告 / 错误反馈。
- 公众号创作：主题 → 选题 → 框架 → 写作 → 反 AI → 配图 → 排版预览 → 下载 / 草稿箱。
- 公众号创作：交互、自动、单步模式；新对话；取消生成；历史版本；选段改写。
- 小红书、贴图号、发布前复核：必填校验 → loading → 结果 / 空状态 / 错误。
- 早安祝福：页面进入 → 生成器加载边界。

## 3. 已修复问题

### P0 / P1

- 修复工作台首屏留白和输入框遮挡欢迎内容。
- 移除高频工作区玻璃模糊，收敛圆角和阴影。
- 关键辅助文字提升到 12px，提高对比度。
- 发送按钮提升到 44px。
- 版本、编辑等图标按钮补齐 aria-label。
- 主要创作表单补齐 name、autocomplete 和数字 inputmode。
- Toast 增加 role 与 aria-live；诊断、预览、发布、选段改写错误改为非阻塞可读反馈。
- 全局补充 focus-visible、touch-action 和弹层 overscroll-behavior。
- 修复服务器旧 systemd release 配置覆盖新版本的问题。

## 4. 剩余问题

### P2

- impeccable 仍报告 151 项历史样式问题，主要是旧主题低对比度、彩色 glow、旧 transition、嵌套卡片、跳级标题、装饰性脉冲点和 html/body 裁切；不影响本轮主要可见流程。
- 全站 1280 / 1024 / 768 / 375 的逐路由视觉截图仍应在后续回归矩阵中补齐，但当前已验证核心工作台断点。
- 公网自动化浏览器受当前环境 ERR_BLOCKED_BY_CLIENT 限制；线上以 HTTP 200、服务进程、GitHub 提交和 CSS SHA256 交叉确认，不把本地截图冒充线上截图。

### P3

- 个别历史页面的元信息字号和术语仍可在组件收敛时统一。

## 5. 浏览器尺寸检查结果

- 1440×900：工作台 920×820，无横向溢出，欢迎区与输入框不重叠。
- 390×844：工作台 374px 宽，document / body scrollWidth 均为 390，无横向溢出。
- 六个主要工具 route 均成功进入对应 section；桌面尺寸探测无横向溢出。
- 67 个单元测试通过；node app.js 语法检查通过；git diff check 通过。

## 6. Accessibility 情况

- 页面 lang 为 zh-CN，viewport 未禁用缩放。
- 主要表单有 label 或 aria-label，已补齐 name / autocomplete。
- 异步产物区有 aria-live，Toast 使用 status / alert。
- 主要图标按钮有可访问名称；导航使用 a，动作使用 button。
- Tab 实测可到达导航，焦点为 2px 可见 outline；移动端无横向滚动。
- reduced-motion 规则存在，工作台 loading 动画在该偏好下停止。

## 7. 是否建议上线

建议上线。RC 范围内无 P0/P1 阻断项；P2 为历史样式和非关键细节债务，进入下一轮维护，不阻塞本次发布。

## 当前基线

- 线上首页独立 HTTP 请求：HTTP 200。
- 页面实际使用多层 CSS：基础样式、主题、组件、布局、对话、工作台等；当前已存在统一化改造层，但历史覆盖规则仍需继续收敛。
- 路由与 API 代码扫描完成，公众号创作主流程为 8 步，后端接口保留不变。
- 本轮回归：67 个单元测试通过，`node --check static/app.js` 通过；工作台浏览器实际检查覆盖 1440×900 与 390×844。
- 1440×900：工作区 920×820，无页面横向溢出；输入框不遮挡欢迎区。
- 390×844：工作区 374px 宽，`document` 与 `body` 的 scrollWidth 均为 390，无横向溢出。
- 线上部署：GitHub `main` 与服务器 release 均为 `2956fb913e671dddd404bacf5f6f9863ccc96984`；Web / worker active，`/health` 返回 200；线上 CSS SHA256 与服务器 release 一致。
