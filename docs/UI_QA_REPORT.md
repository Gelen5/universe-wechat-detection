# UI QA Report

## 当前基线

- 线上首页独立 HTTP 请求：HTTP 200。
- 页面实际使用多层 CSS：基础样式、主题、组件、布局、对话、工作台等；当前已存在统一化改造层，但历史覆盖规则仍需继续收敛。
- 路由与 API 代码扫描完成，公众号创作主流程为 8 步，后端接口保留不变。
- 已有项目回归记录：39 个单元测试曾通过；工作台浏览器回归覆盖桌面与移动端，后续 UI 改造后必须重新执行。

## 当前阻塞

浏览器自动化会话访问线上域名时被当前网络策略返回 `ERR_BLOCKED_BY_CLIENT` / `ERR_CONNECTION_CLOSED`；因此本报告不声称已完成线上逐页截图验收。首页 HTML 已通过独立 HTTP 获取，作为线上资源基线。

## 验收门槛

- [ ] 所有主路由在 1440 / 1280 / 1024 / 768 / 390 / 375 无横向溢出。
- [ ] 所有异步操作有 loading / success / error / retry。
- [ ] 所有表单有 label、帮助、就近错误和提交反馈。
- [ ] 所有图标按钮有可访问名称，焦点可见，键盘顺序合理。
- [ ] 公众号 8 步流程从输入到预览、下载、草稿箱写入可复测。
- [ ] 运行最新 Web Design Guidelines 审计并清零 P0/P1。
