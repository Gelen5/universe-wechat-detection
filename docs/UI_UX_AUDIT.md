# 宇宙第一工作台 UI / UX Audit

> 基线日期：2026-09-12。线上地址：http://yuzoudiyigongzuotai.cn/。首页通过独立 HTTP 请求返回 200；浏览器自动化会话受当前网络策略拦截，因此交互结论同时以线上 HTML、仓库代码和已有浏览器回归脚本为证据，不把本地截图当作线上现状。

## 产品与用户主路径

产品是一个多 Skill 创作工作台。核心路径是：登录/注册 → 选择公众号创作 → 输入主题 → 选题 → 框架 → 写作 → 反 AI → 配图 → 排版 → 预览 → 写入草稿。诊断、爆文检测、小红书、贴图号和早安祝福是并列工具；积分、API 设置、管理员用户与任务是全局管理能力。

## 主要问题

## Brutal critique 分级

以下结论来自 `npx impeccable detect`（初始 155 项，首屏修复后 151 项）、本地浏览器在 1440×900 与 390×844 的实际检查，以及线上独立 HTTP 资源核对。分级按“是否阻断任务 / 是否伤害高频效率 / 是否属于上线质量门槛”判断。

### P0 — 阻断或误导核心任务

- 首屏的旧布局规则给创作入口增加了无意义的大块垂直留白，并让输入框在小视口覆盖欢迎内容；已通过收敛首屏决策区和工作台高度修复。
- 线上服务存在多个互相覆盖的 systemd release drop-in，导致部署后仍可能运行旧目录；已增加最终优先级 release 配置并核对 Web / worker 均运行当前提交。

### P1 — 明显降低完成率与信任感

- 工作台标题栏和输入框使用玻璃模糊，和生产工具的克制、高密度定位冲突；已改为实体白底和中性阴影。
- 辅助信息大量使用 10–11px，状态与 Skill 执行信息难读；工作台关键辅助文本已提升到 12px 并提高对比度。
- 主发送按钮为 38px，低于移动端可靠触控目标；已提升为 44px。
- 工作台多个层级使用 10–14px 圆角与阴影，形成 AI SaaS 模板感；已压平高频工作区的圆角和阴影层级。

### P2 — 需要持续收敛的系统问题

- 历史页面仍有低对比度文本、彩色 glow 阴影、过渡 `width`、嵌套卡片、跳级标题和装饰性脉冲点；这些不再作为公众号工作台的新设计模式，但需要按页面逐步清理。
- 全站仍存在 `html/body` 裁切、部分表单状态与异步错误反馈不完整等遗留项；公众号工作台的本次首屏修复不等于全站已清零。

### P3 — 可延期的细节

- 个别历史模块的 10px 元数据、装饰符号和文案密度仍不统一；不阻断主流程，但应在下一轮组件收敛时删除。

### 信息架构

- 主导航同时承载创作工具、诊断工具和轻量图片工具，用户需要自己推断它们之间的关系。
- 公众号创作是最高价值路径，但页面同时呈现助手、流程轨、文章画布、结构版本和底部行动区，首要动作不够单一。
- 全局设置、积分和管理员入口依赖头像菜单；这是合理的二级位置，但菜单项应按“个人 / 管理 / 退出”分组。

### 页面布局

- `/workbench` 的对话区与文章画布是合理的 Split View，但在窄屏上必须变成“对话 → 当前产物 → 下一步”单列顺序，不能保留嵌套滚动。
- 固定底部操作区需要预留内容底部空间，避免遮挡编辑器和键盘焦点。
- 选题卡需要完整展示 10 条，同时控制每条的信息层级；不应把搜索证据、评分解释全部展开在首屏。

### 视觉层级

- 1 秒：用户应看到当前工具名和唯一主动作；目前多处状态、说明和按钮同时竞争。
- 3 秒：用户应知道输入什么、结果在哪里、下一步是什么；公众号创作需要把“输入主题”放在首要视觉入口。
- 10 秒：用户应理解 Skill 会逐步执行并在关键节点等待确认；执行证据应放到可展开区域，不抢主任务。

### 交互与状态

- 需要统一 Default / Hover / Focus / Disabled / Loading / Success / Error 状态。
- 所有异步生成应在按钮上显示进行中状态并防止重复提交，结果区域使用 `aria-live`。
- 失败提示必须同时说明原因和修复动作，例如 API 非 JSON、余额不足、图片生成失败、草稿未写入。
- 多步骤流程必须提供返回、取消和恢复路径；当前“下一步”与“预览/发布”需要更清楚地区分可逆编辑和外部写入。

### 响应式与可访问性

- 目标断点：375 / 390 / 768 / 1024 / 1280 / 1440。
- 保持 `viewport` 缩放能力；移动端正文输入至少 16px，触控目标至少 44px。
- 图标按钮要有 `aria-label`，装饰图标使用 `aria-hidden`，所有表单控件要有可见 label 或等价语义。
- 图片需有明确尺寸、`alt` 和非首屏懒加载策略；长标题、URL、用户素材必须可换行。

## 设计决策

采用 UI/UX Pro Max 检索到的 Flat Design 方向：浅色内容优先、青绿色主色、橙色作为少量行动强调、无渐变/无大面积阴影、统一 SVG 图标。Impeccable 作为审计门禁，重点删除重复卡片、无意义说明和平均分布的信息；Web Design Guidelines 作为最终验收门禁，重点检查表单、焦点、响应式、媒体尺寸和异步反馈。本轮不新增视觉方向，只修复阻断项和工作台高频路径上的视觉噪声。
