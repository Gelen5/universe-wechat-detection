# 去 AI 节点与模型配置

- 默认一轮定位 + 一次局部改稿 + 修订后本地审计。最后一轮不再跳过改稿。
- 原文没有可安全修改的问题时允许不变，报告必须明确说明；不为制造差异强改事实或引语。
- 新稿重新检查保真、完整句和篇幅；保真丢失不能标为通过。
- 去 AI 节点默认 240 秒预算，单个模型请求最多 90 秒，不再从适配器重跑整个复核。
- 进度分为定位、局部改稿、修订稿检查；取消后关闭活动工具记录，后续模型调用检查取消状态。
- 不同提示词使用不同的稳定请求键，避免中转将诊断与改稿误认成同一请求。
- 文字模型默认 gpt-6.1-sol，WECHAT_REASONING_EFFORT=medium；Sol 使用 Responses API。
- 生产部署还需更新数据库 text_model 与各节点环境变量；保留 API 域名、密钥、图片模型。
- 无任何外部 AI 检测调用，不承诺检测分数。

验证：tests/test_review_delivery.py、原有复核回归、provider、任务取消与积分测试。
